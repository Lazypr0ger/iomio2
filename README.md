# Лабораторная работа №2
## Многомерная нелинейная оптимизация

**Вариант:** 3  
**Среда:** Python 3.12, виртуальная среда `venv`  
**Корневая папка проекта:** `iomio2`

Проект реализует решение задач безусловной минимизации тремя методами:

1. Метод сопряжённых градиентов Флетчера–Ривза.
2. Модифицированный метод Ньютона.
3. Метод BFGS.

Готовые методы оптимизации из `scipy.optimize` не используются.

## 8. Реализованные методы

### 8.1 Метод сопряжённых градиентов Флетчера–Ривза

Файл реализации:

```text
src/methods/conjugate_gradient.py
```

Используемые формулы:

```text
p_0 = -g_0
p_k = -g_k + β_k p_{k-1}
β_k = ||g_k||² / ||g_{k-1}||²
```

Особенности реализации:

- рестарт каждые `n` шагов, если частота рестарта не задана вручную;
- если направление перестаёт быть направлением убывания, выполняется сброс на антиградиент;
- длина шага выбирается бэктрекингом Армихо.

### 8.2 Модифицированный метод Ньютона

Файл реализации:

```text
src/methods/newton.py
```

На каждой итерации решается система:

```text
H_k p_k = -g_k
```

Особенности реализации:

- если Гессиан не является положительно определённым, используется регуляризация `H_k + μI`;
- положительная определённость проверяется через разложение Холецкого;
- если СЛАУ плохо решается, используется псевдообратная матрица;
- длина шага выбирается бэктрекингом Армихо.

### 8.3 BFGS

Файл реализации:

```text
src/methods/bfgs.py
```

В реализации хранится приближение обратного Гессиана.

Направление поиска:

```text
p_k = -H_k^{-1} g_k
```

Условие обновления:

```text
y_k^T s_k > 0
```

Если условие кривизны не выполнено, приближение обратного Гессиана сбрасывается к единичной матрице.

## 9. Подбор шага

Файл реализации:

```text
src/methods/line_search.py
```

Для всех методов используется бэктрекинг Армихо:

```text
f(x + λp) <= f(x) + c1 * λ * ∇f(x)^T p
```

Параметры по умолчанию:

```text
epsilon = 0.001
initial_step = 1.0
armijo_c1 = 1e-4
backtracking_factor = 0.5
min_step = 1e-12
max_iterations = 1000
```

## 10. Полином 10D

Файл реализации:

```text
src/functions/polynomial_10d.py
```

Структура полинома:

```text
f(x) = Σ dᵢxᵢ² + Σ cᵢⱼxᵢxⱼ + Σ lᵢxᵢ + αxₖ^p
```

Для варианта 3 в таблице указано:

```text
diag = [9.8, 5.1, 7.5, ...]
5 cross
0.043 * x3^6
x0 = (-1.5, -2.4, 2.5, ...)
```

Так как в таблице не раскрыты все коэффициенты, недостающие коэффициенты заданы явно и воспроизводимо в коде. Это соответствует условию, по которому не заданные коэффициенты могут быть приравнены к нулю или выбраны произвольно.

## 12. Особенности реализации

- Для всех 2D-функций градиент и Гессиан заданы аналитически.
- Для полинома 10D градиент и Гессиан также заданы аналитически.
- Готовые оптимизаторы из `scipy.optimize` не используются.
- Основная линейная алгебра выполняется средствами `numpy.linalg`.
- Есть защита от плохих направлений поиска.
- Есть ограничение по максимальному числу итераций.
- Есть консольный и web-интерфейс.
- Графики строятся автоматически программой, не вручную.
